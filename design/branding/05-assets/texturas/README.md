# Texturas — papel y grano

Fondos de papel con grano fino y fibras sutiles, 2048×2048 (tileables a ojo,
sin costura visible en uso normal). Generadas sobre los neutros de la paleta.

| Archivo | Base | Uso |
|---|---|---|
| `papel-hueso_2048.jpg` | Hueso `#FAF8F1` | Fondo web/print por defecto, papelería |
| `papel-crema_2048.jpg` | Crema `#F6F4EC` | Superficies, tarjetas, packaging |
| `grano-carbon_2048.jpg` | Carbón `#1E2523` | Fondos oscuros premium, footer, merch |

## Reglas
- La textura reemplaza al color plano — nunca ambos con opacidad alta.
- En web usar como `background-image` con `background-size: 1024px` (o 50%)
  para que el grano no se vea pixelado en pantallas retina.
- Nunca blanco/negro puro: estas texturas existen justamente para eso.
