# Patrones — tramas seamless

Tramas sutiles en gris niebla `#DDE0DA`, pensadas para fondos (reverso de
etiqueta, packaging interior, web, papelería). SVG con `<pattern>` reutilizable
— el tile se puede extraer del `<defs>` o usar el archivo como fondo directo.
Previews sobre crema: `_preview_*.png`.

| Patrón | Tile | Carácter |
|---|---|---|
| `trama-puntos.svg` | 48×48 | Retícula de puntos offset — la más discreta, casi textura |
| `trama-meridianos.svg` | 96×96 | Líneas + meridianos curvos — eco del globo del isotipo |
| `trama-botanica.svg` | 160×160 | Ramitas y hojas alternadas — la más ilustrativa |
| `trama-olas.svg` | 96×64 | Olas continuas — mar, reef safe, línea Sunscreen |

## Reglas
- Siempre **sutiles**: sobre Hueso/Crema mantener el contraste bajo (niebla).
  Sobre fondos oscuros, recolorear el stroke a Slate 700 `#495654`.
- No usar como protagonista: son fondo, nunca compiten con logo o texto.
- Densidad: si la pieza es chica, usar `trama-puntos`; la botánica pide aire.
