# Lockups

Wordmark con área de seguridad aplicada, sobre los fondos clave de la paleta.
Cada fondo usa el color de logo con mejor contraste. Disponibles en `vertical` y
`horizontal` — archivo: `{orientacion}_sobre-{fondo}.png`.
