## Resumen de identidad
- **Logo**: wordmark hand-lettered "SELVA BRAVA" (2 orientaciones, 3 colores).
- **Verde de marca**: `#4C6759`.
- **Neutros**: crema `#F6F4EC` · tinta slate `#687978` · gris niebla `#DDE0DA`.
- **Acentos**: Sunscreen salvia `#A9B59D` · Cacao terracota `#B97E6B` · Moist salvia lavada.
- **Estética**: raw, orgánica, vintage-outdoor / apothecary premium.
