# Isotipo — el símbolo

El emblema sin el wordmark: globo con retícula de meridianos dentro del anillo
"EARTH FRIENDLY ORGANIC SKIN CARE PRODUCTS". Recoloreado al palette del full
badge canónico (tinta slate teal `#687978`, globo `#BBC6AA`) para consistencia.

## Archivos
- `selva-brava_isotipo.svg` / `.png` — vector + PNG transparente.

## Uso
- Marca de agua, sellos secundarios, patrones, watermark sobre fotografía.
- Para avatar / favicon muy chico el globo pierde legibilidad: preferir el
  favicon basado en el wordmark (`../favicon/`).
