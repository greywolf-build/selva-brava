# 05 · Assets

Recursos gráficos reutilizables del sistema (§8 del manual de marca).

| Carpeta | Contenido | Formato |
|---|---|---|
| `sellos/` | 5 badges de confianza: REEF SAFE, 100% ORGANIC, EARTH FRIENDLY, SPF 60, SPF 20 — en slate/bosque/hueso + fuente editable | SVG (vectorizado) + PNG 1024 |
| `iconos-botanicos/` | 8 iconos de línea: hoja, rama, ramita, brote, sol, montaña, ola, gota | SVG (`currentColor`) |
| `patrones/` | 4 tramas seamless en niebla: puntos, meridianos, botánica, olas | SVG `<pattern>` + previews |
| `texturas/` | Papel hueso / crema / grano carbón | JPG 2048² |

Cada carpeta tiene su `README.md` con tabla de archivos y reglas de uso, y un
`_preview.png` para vista rápida (texturas: ver los JPG directamente).

**Regla general:** todo asset se recolorea solo dentro de la paleta
(`../02-color/paleta.md`) y se usa como soporte — nunca compite con el logo.
