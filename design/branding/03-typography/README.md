# 03 · Typography

- `tipografia.md`            — sistema de fuentes por rol (display / body / script / datos), jerarquía, escala y reglas.
- `muestra-tipografica.png`  — espécimen del sistema completo.
- `mockups-tipografia.png`   — aplicaciones resumidas (packaging, social, e-commerce, editorial) con color de marca.
- `examples/`                — 10 piezas de diseño extensas aplicando el sistema (web, poster, story, editorial, packaging, carrusel IG, hang tag, papelería, escala, merch). Ver `examples/README.md`.
- `fonts/`                   — archivos TTF con licencia **SIL OFL** (redistribuibles) + `OFL-*.txt`:
  - Display → `BarlowCondensed-{Medium,SemiBold,Bold}` · alterna `Anton-Regular`
  - Body    → `Barlow-{Regular,Medium,SemiBold}`
  - Script  → `Caveat-Variable` (wght 400–700; usar ~600 en display) · alternas: Yellowtail / Kaushan Script
  - Datos   → `SpaceMono-{Regular,Bold}`
