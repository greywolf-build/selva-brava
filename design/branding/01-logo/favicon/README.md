# Favicon / App icon

centrado. Esquinas transparentes (se adapta a cualquier fondo).

- `favicon_512.png` — master (PWA / app icon).
- `favicon_180.png` — apple-touch-icon.
- `favicon_32.png`, `favicon_16.png` — favicon web.
- `favicon.ico` — multi-resolución (16/32/48) para navegadores.
