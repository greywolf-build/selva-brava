# Iconos botánicos / outdoor

Set de 8 iconos de línea (stroke 2.3–2.5, puntas redondeadas, viewBox 64×64),
mismo pulso que los motivos del sello. Vista rápida: `_preview.png`.

| Icono | Uso típico |
|---|---|
| `hoja.svg` | Orgánico, natural, ingredientes |
| `rama-eucalipto.svg` | Botánica decorativa (flanquear sellos, cierres) |
| `ramita.svg` | Viñetas, listas, separadores |
| `brote.svg` | Regeneración (Moist), crecimiento |
| `sol.svg` | Protección solar, SPF |
| `montania.svg` | Outdoor, altura, condiciones exigentes |
| `ola.svg` | Playa, surf, reef safe |
| `gota.svg` | Hidratación, fórmula |

## Uso
- Color vía **`currentColor`**: heredan el `color` del contexto (CSS) o
  reemplazar `currentColor` por un HEX de la paleta.
- Tinta recomendada: Slate `#687978` o Bosque `#4C6759` sobre claros;
  Hueso `#FAF8F1` sobre oscuros.
- No rellenar (son de línea), no mezclar con iconos de otra familia visual.
- Escalar siempre proporcional; grosor óptico correcto entre 20 y 64 px.
