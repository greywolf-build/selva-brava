# Examples — Tipografía en uso

Piezas de diseño que aplican el sistema tipográfico (Barlow Condensed · Barlow ·
Caveat · Space Mono) con la paleta de marca (ver `../../02-color`). Todas generadas
con las fuentes reales de `../fonts/`.

| # | Archivo | Pieza | Registro tipográfico destacado |
|---|---|---|---|
| 01 | `01_web-hero.png` | Hero de landing (nav + producto + CTA) | Display XL + body + acento + data |
| 02 | `02_poster-campania.png` | Poster de campaña (vertical, invierno 2026) | Display gigante + Caveat + mono |
| 03 | `03_story-9x16.png` | Story / anuncio vertical 1080×1920 | Display + acento + CTA |
| 04 | `04_editorial-articulo.png` | Artículo de revista/blog (2 columnas) | Jerarquía completa + pull-quote Caveat |
| 05 | `05_packaging-label.png` | Etiqueta de producto (frente + dorso) | Front display + back Space Mono (ingredientes) |
| 06 | `06_instagram-carousel.png` | Carrusel IG de 4 slides | Cover / mito / data / CTA |
| 07 | `07_hangtag.png` | Hang tag / etiqueta colgante (frente + dorso) | Display + acento + specs mono |
| 08 | `08_stationery.png` | Papelería / tarjeta personal (frente + dorso) | Wordmark + body + contacto mono |
| 09 | `09_type-scale.png` | Escala tipográfica en contexto | Referencia de jerarquía 50→data |
| 10 | `10_merch.png` | Merch (tote · tee · stickers) | Lockups de wordmark e isotipo |

## Notas
- Los textos son **placeholder realista** (claims, precios, ingredientes de ejemplo);
  ajustar a copy e info legal definitivos antes de producción.
- Colores usados: neutros + acentos Salvia/Terracota y escaleras de `../../02-color`.
- Reglas aplicadas: display en MAYÚS con tracking, Caveat en 1 palabra/frase corta,
  Space Mono para todo dato/spec/precio, nada de blanco/negro puro (Hueso/Carbón).
